# Manual extraction corpus

These manuals are local regression fixtures representing varied language, table quality, feature complexity, and manufacturer conventions.

| Manual family | Expected pressure test |
| --- | --- |
| Betopper LB150 | Image-only scan, 16-bit pan/tilt, color and gobo wheels, hazardous reset channel |
| SHEHDS 200 W strobe | Prosumer table vocabulary and strobe safety ranges |
| Chauvet DJ FXpar 6 | RGB/effect fixture with several operating modes |
| Chauvet DJ Rotosphere HP | Rotating effect rather than ordinary pan/tilt |
| Chauvet DJ Sentinel Wash Q7Z ILS | Large modern multi-mode fixture |
| ADJ Vizi Xtreme | Separate manual and DMX-traits documents |
| ADJ Hydro Hybrid | Complex hybrid mover and maintenance controls |
| ADJ LP HEX 12 Plus | Traits-only RGBWAUV fixture data |
| Generic LED120W | Sparse/generic manufacturer document |
| 19 × 20 W RGBWAUV mover | Non-English filename and dense matrix-like channel data |
| Altman Spectra | “Personalities” terminology and number words for channel counts |
| Altman PHX LVD | Negative fixture: mains/phase-cut dimming, no DMX table; extraction must not invent a DMX profile |

Corpus PDFs may remain subject to their manufacturers' copyrights. They are test inputs, not MIT-licensed project source, and should be reviewed before public redistribution.
