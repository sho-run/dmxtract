What is a fixture profile?

A DMX light listens to numbered controls called channels. One channel might be brightness, another red, another pan, and another a wheel of gobos. A fixture profile tells your software what every channel and value means so it can show useful controls instead of 20 mystery sliders.

Two useful open formats

OFL

Open Fixture Library

OFL is a community-maintained JSON description of a fixture's DMX modes, channels, ranges, wheels, and physical details. The Open Fixture Library can turn that shared description into files for several lighting applications.

Its current export list includes:

  • sho.run, which can import OFL JSON as a custom fixture
  • QLC+ 4.12.2
  • DMXControl 3
  • Millumin
  • e:cue

See OFL's current export formats.

GDTF

General Device Type Format

GDTF is an open interchange format for consoles, design tools, and visualizers. A GDTF file can describe DMX behavior as well as wheels, emitters, geometry, and other physical details when that information is available.

Documented GDTF workflows include:

  • MA Lighting grandMA3
  • ChamSys MagicQ
  • ETC Eos
  • Vectorworks Spotlight and Vision workflows
  • sho.run, which can import GDTF as a custom fixture
Which one should you download?

Choose the format named by your lighting software. If it supports both, OFL is excellent for open fixture-data sharing and GDTF carries a broader device description. Support can vary by software version, and complex fixtures should always be checked before a show. DMXtract's first GDTF exports use a basic fixture shape when no authorized 3D model is available.

Open DMX does not always mean open profiles

These are two different layers. Art-Net and sACN are open ways for an app to send DMX values across a network. OFL and GDTF are ways to describe what those values mean for a particular light.

Luminair supports open network output including Art-Net and sACN, but its current documentation describes its own Fixture Cloud and in-app profile creator rather than direct OFL or GDTF import. Lightkey also has a built-in library and profile editor, but does not currently document direct OFL or GDTF import. Obsidian ONYX uses an AtlaBase-backed fixture library and its own Fixture Library Editor; its documented patch exchange still matches fixtures against that library rather than importing OFL or GDTF definitions. A DMXtract v1 export therefore does not import directly into these apps today.

That gap is part of the reason portable fixture data matters. DMXtract starts with OFL and GDTF because they are open, documented targets; additional open adapters can be built without making your fixture information start over again.

Open information lifts every show

A useful fixture profile should not be trapped in one person's show file or one manufacturer's download portal. DMXtract is an MIT-licensed project because a profile corrected by one student, volunteer, DJ, programmer, or venue can save the next person hours of frustration.

The manual and photos stay on your device. You can save an editable DMXtract project, export OFL and GDTF, and contribute improvements wherever those communities accept them.

Test it. Then pass it on.

If you have tested your profile on the real light and you are feeling altruistic, consider contributing it to the Open Fixture Library or uploading it to GDTF Share. Tell the community what you tested, and check each library's contribution requirements before submitting.

There are tens of thousands of fixture models spread across more than a thousand manufacturers, house brands, and white-label names. The faster these shared libraries grow, the more confident everyone can be that a new app or console will recognize the lights they already own—and produce one fewer headache than the last one.
